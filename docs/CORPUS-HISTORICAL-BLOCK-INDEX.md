## Reglas

- Un rango numérico no identifica por sí solo una definición única.
- Dos bloques con el mismo rango pero tema distinto se conservan como fuentes distintas.
- `NO RECUPERADO` significa que todavía no apareció evidencia suficiente en resúmenes/artefactos disponibles; no significa que el bloque nunca existiera.
- Este archivo es índice de procedencia, no lista canónica de requisitos.
