## Fuera de alcance y verificación

No producción, datos personales, credenciales ni redes. El paquete V11 se
probó localmente tras recibir una reserva V3 activa y acreditar cuota GitHub
autenticada superior a 1200 solicitudes. La rama, CI exact-HEAD y revisión
CodeRabbit requieren evidencia terminal independiente; CodeRabbit solo se
solicita una vez sobre el PR final y con CI verde. Ningún status de producto
se ha promovido sin demostrar la totalidad del requisito correspondiente.
